## at

```bash
sudo apt install at
at 22:00
at> /usr/local/bin/manutencao.sh
at> <Ctrl+D>

echo "reboot" | sudo at now + 30 minutes
at -t 202611200300 < tarefa.sh     # 20/11/2026 às 03:00

atq        # lista tarefas pendentes
atrm 3     # remove a tarefa 3
```

O acesso é controlado por `/etc/at.allow` e `/etc/at.deny`, como no cron.

## systemd-run

Cria um timer transitório, sem precisar escrever arquivos:

```bash
sudo systemd-run --on-active=30m /usr/local/bin/manutencao.sh
sudo systemd-run --on-calendar='2026-11-20 03:00' systemctl reboot
systemctl list-timers
```

## Exercícios

1. Crie uma tarefa no cron que grave `date` em `~/cron.log` a cada 5 minutos e confira.
2. Converta essa tarefa para um timer do systemd com `Persistent=true`.
3. Agende com `at` uma mensagem (`wall "Teste"`) para daqui a 2 minutos.
