Diferente do Windows e do macOS, no Linux a interface gráfica é um **programa à parte**
e pode ser trocada. Os principais ambientes de desktop são:

| Ambiente | Características |
|---|---|
| **GNOME** | Moderno e minimalista; padrão no Ubuntu e Fedora. |
| **KDE Plasma** | Muito configurável; visual parecido com o Windows. |
| **XFCE** | Leve e tradicional; ótimo para computadores mais antigos. |
| **Cinnamon** | Padrão do Linux Mint; familiar para quem vem do Windows. |
| **LXQt** | Extremamente leve. |

## Elementos comuns

- **Painel/barra** com menu de aplicativos, relógio e área de notificação;
- **Gerenciador de arquivos** (Nautilus, Dolphin, Thunar);
- **Áreas de trabalho virtuais** (*workspaces*);
- **Central de programas** para instalar aplicativos graficamente.
